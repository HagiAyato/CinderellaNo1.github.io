# シンデレラNo1 再生補助用ページ

## 概要
シンデレラガール総選挙2026企画の一つである各アイドルのデレステコミュ+シンデレラNo1歌詞公開動画の再生補助を行うページです。

## 機能
### 各アイドルのシンデレラNo1の部分から再生する機能(デフォルト機能)
文字通り各アイドルのシンデレラNo1の部分だけ190名分ランダムで連続して再生します。
表中のアイドルの名前をクリックするとそのアイドルに移動します。
表はリロード毎にシャッフルされます。
### 応援再生モード
Youtubeのアルゴリズムにポジティブ(パッション)なカウントを残す為に各アイドルの最初のコミュから５~６分間(動画内における10~12分間)倍速再生します。
5~6分もしくは動画の最後に達すると次の動画へ移ります。
### 他
XにシンデレラNo1部分のURLを投稿するボタンが表の中にあります。

## Q&A
### 190名じゃなくて特定のアイドルだけで回したい
⇒そこまでの実装はしません。
ただし、後述の通りHTMLソースは自由に使用してかまいませんのでNetlifyや自前鯖等に実装した際に特に回したいアイドルだけのリストにして回す等でご対応ください。
### 総選挙のデイリーミッションが達成できてない
⇒仕様です。総選挙のミッションクリアはあくまで総選挙のページ内で動画を開いた際にカウントされます。
こちらのサイトやYoutubeで直で見ただけではカウントされませんのでご了承ください。
### 正しく再生カウントされるの？
⇒わかりません。
Youtubeはどうやったらカウントされるかの情報は非公開なのでこれをすれば正しいという正確な情報はありません。
(再生やアクセス状況等を見てカウントする、しないような挙動してる感じはします。)
動画の再生URLを界隈外にも拡散し、一人でも多くの方々が視聴していただけるとより効果的かもしれません。
